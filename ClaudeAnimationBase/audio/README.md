## 实测

**母带：-14.00 LUFS (I) · -1.06 dBTP（4× 过采样；ffmpeg ebur128 读 -0.90，交付侧 TP 由你处理）· LRA 5.50 LU**；峰值 -2.16 dBFS、无削波、无 NaN。
0.5 s RMS **-32.7 → -9.6 dBFS**；1 s RMS **-30.7 → -10.4**；波峰因数 均值 14.61 / 最低 9.06。
D9：**gap 6.95–7.45 s → +7.41 dB**（窗口 -24.66，人声 -17.25）· **endcard 43.70–45.90 s → +14.70 dB**（窗口 -25.07，人声 -10.38，垫层 -29.93）。
重音帧误差 **+0.13 / -0.12 / +0.25 / -0.28 帧**（max 0.28）；SFX **16 条**。

## 坑与规避（新增）

1. **自研曲必须缓存**：一次合成 ~5.6 min（约 1300 个 Sound），`bed_cache/` 按 bpm+相位+切点+时长+seed 做键。
2. **mgaudio 的鼓/合成音使用全局 RNG**：作曲前必须 `reset_rng`，否则每次渲染都不一样、缓存也失效。
3. **网格相位要挑**：切点与等速网格不可能全部对齐，先扫拍相位（使 5 个切点总偏移最小），再用 0 帧误差的自研事件兜底。
4. **过采样真峰值表与 ffmpeg ebur128 会在密集素材上分歧 ~0.16 dB**：验收只认自己的 4× 表，另一个值并列报告。
5. 垫层音量上限（`--bed-max-db`）会吃 D9 余量：自研曲更密、幕间窗口更响，需把 gap 电平再压 1.5 dB 才回到 ≥6 dB。
